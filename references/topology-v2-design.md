# Topology V2 样板与实现说明

日期：2026-10-30。依据：[正式设计规范 v1.0](topology-design-standard.md)及 SST 图标 v4。正式规范的 47 项确认记录是设计权威；本文说明当前样板的实际能力和格式。

## 当前交付

使用 `node tools/build_topology_v2_design.js` 构建 `outputs/Topology_V2_Design/index.html` 自含离线样板册；也可通过 `--output <目录>` 指定输出位置。八类构图、一个环网组合示例、一个六类连线图谱，合计 26 个深浅主题／视图变体。分层、双中心、泳道提供总览与工程详图；模型保留稳定 ID 和成员映射。

- 主体构图：分层、中心辐射、双中心、环形、网格、嵌套区域、泳道、无连线能力全景。
- 组合示例：完整环网 + 两侧站点 + 环内真实设备，支线使用与环段分开的内外侧接点。
- 连线图谱：独立物理主备与逻辑隧道、同类成员管道、真实总线、多色业务比较、数据包与管理关系、沿基础线的业务叠加。
- 操作：主题、深浅对照、总览／详图、业务选择、缩放／全屏、静态 SVG／PNG、完整 JSON 模型；布局编辑、撤销重做、可编辑 HTML 保存与 JSON 导入。
- 默认静态；泳道默认只突出实时交互，可切换业务，选择“所有业务”才比较。系统减少动态效果设置优先。包数、速度、线宽和色带不代表实测数值。

## 同步的视觉规则

普通层级、成员集合和线谱分组用标题、对齐及留白，不套装饰框。站点、网络、安全、管理和能力范围保留有语义的边界。整体可以横向阅读，局部继续纵向、环向或网格排布。

基础线路中性；物理实线、逻辑虚线、管理点线。主备、RPL 和故障使用独立身份或状态标记，不因备用而把物理线改成虚线。独立线路有独立边 ID；聚合管道保存成员数量、成员 ID、端点和属性。业务强调层直接引用 `base_edge` 的几何，保留可辨认的中性底线和方向，不平移成另一条物理线。

默认圆角折线最多转弯两次；标准／紧凑圆角为 12／8px，并受短段限制；并行线中心距为 12／8px。显式直线不得带折点或偷偷退化成正交线。扇出按局部轴线分配中心与镜像接点，四个方向均可使用非 45 度端点；已有八方位输入保持兼容。带下方胶囊的双核心采用更靠近底部中轴的一对镜像接点，避开胶囊；不机械沿用固定角度。样板端点与走廊均为人工选定，不宣称完成通用端口求解。

## 当前 SST 图标、组合标记和字体

共享源 `assets/sst-icon-system.json` 保存 12 类已确认 SST 图标的类别表、四种组合图形和 v4 布局参数，Node 与旧 Python 使用同一份。尚无 SST 图形的类型继续使用中性图标，80 类整库尚未完成。

| 项目 | 标准 | 紧凑 |
| --- | --- | --- |
| 圆盘直径／正常外圈 | 84px / 2.4px | 64px / 2.4px |
| 无组合标记的可见图形 | 圆径约 61.8%，居中 | 圆径约 61.8%，居中 |
| 有组合标记的可见图形 | 最长边 41.5px，中心 y=-14 | 最长边 26px，中心 y=-14 |
| 圆内下方组合胶囊 | 高 28px，底边内收 5px | 高 26px，底边内收 5px |
| 设备名 | 圆外下方，至少 13px | 圆外下方，至少 13px |

`nodes[].deployment` 为 `ha`、`stack`、`cluster`、`mlag`，与 `status` 独立。胶囊符号及文字按 `sst-tag-metrics.json` 的实际字形整体居中，允许左右等量轻微超出。组合标记不自动创建成员或连接。能力图中标记为概念表达；物理设备的组合成员须由事实模型给出。正常与备用设备均保持实心外圈，备用另用暂停状态标记；重点设备可用 3px 外圈。

英文使用原版 IBM Plex Sans Regular / SemiBold，字体 WOFF2、固定源版本、哈希和 OFL 1.1 许可随 HTML／SVG 嵌入，无需安装或联网。中文沿用 Source Han Sans SC / Microsoft YaHei 后备。深浅主题读取当前 SST 主题类别色，文字及必要线路另按实际背景检查对比度。

## 环网实现

`rings` 保存 `id`、`cx`、`cy`、`rx`、`ry`、有序 `members`，可选 `startAngle`、`clockwise`、`phase`、`width`。`ringPositions` 使用弧长累计表与反查使节点近似等弧长排列；`phase` 用于在允许条件下整体调整起点，保持真实邻接和边 ID 不变。

环段声明 `geometry: ring` 和 `ring` ID。所有环段属于同一条精确椭圆，数值求交裁切到对应设备外圆周；不再仅以中心端点依赖设备遮罩。需要并行轨迹时仍沿共中心椭圆展开。完整可见真实边覆盖周期时可保留轻微基线；缺边或筛选隐藏边时不补闭环。主样板的 RPL 为独立阻塞状态，物理环段保持连续实线。

名称默认水平下置。长环节点名使用唯一短名并在 `full_label` 保留全称。组合图外部站点从外侧径向扇区连接，环内业务设备从内侧扇区接入，环段接点保持独立；有 6 点支线冲突的站点网关名称移至侧下方。

## 字号与说明框

继承上轮统一减小 1px 的图内字号：标题 27、区域名 17、设备名／副标题 13、说明标题 14、备注／线路／图例 11、附属信息／英文标识 10、页脚 9px。最新组合胶囊按图标 v4 的独立 12.5／11.5px 字形参数使用，不当作设备名缩放。

副标题、区域备注、独立说明、线旁标签和页脚共用安静的主题文本框：1px 中性边、4px 圆角、内容收紧与受限宽度换行。文本框是真实障碍物，不能覆盖设备、名称或线路。线路标签置于清晰可归属线段旁，必要时引出。

## 样板模型

模型记录 `schema_version: 2`、`standards_version: 1.0`、`icon_revision: sst-v4`、`stage: visual-specimen`、`coordinates: curated`、`generated_at`、实际 `design_tokens`、`overrides` 与 `exceptions`。`nodes`、`groups`、`edges`、`rings`、`junctions`、`member_edges`、`views` 和聚合映射保留可追溯数据。

边记录稳定 ID、`source`／`target`、`semantics`、`certainty`、`status`、方向、角色、几何与标签。区域级关系标明 `abstraction: region`，不冒充设备接口。业务边以 `base_edge` 引用现有基础边；聚合 `members` 引用完整成员记录。V2 JSON 不能直接交给旧 Python 渲染器。

## 验证与边界

可运行仓库提供的环形几何、标准、编辑器、吸附和浏览器检查。检查输出位于生成目录的 `verification/`，覆盖模型引用／成员、语义线型、端点与转弯、对比度、字体与胶囊几何、标签避让、环路连续性和按钮导出内容。浏览器系统保存不作为成功项，以按钮实际 Blob 字节和独立重开验证导出内容。

126 组环形参数覆盖 3／4／6／8／12／20／40 节点、圆和横竖椭圆、双方向与三种起始角；高节点数使用足够半径，验证等弧长、外缘端点、反向路径、基线事实闭合及并行弧形。

样板初始坐标仍由人工编排，现已提供浏览器布局编辑；不等于完整自动布局、一般端口分配、地理拓扑、双环共享设备／物理边求解、故障态业务绕行、增删对象／连接等结构编辑或全部最小验收场景均已完成。规范第 9 节保留这些实际边界；不把视觉样板标为通用工程引擎验收。


## V2 布局编辑与文件往返

点击“编辑”进入布局模式，初始仍为浏览模式。设备、区域、真实接点、备注、设备名称和线路标签可拖动；嵌套区域带全部子区域及成员，内部线路随动，外接线路重新贴合端点。选中线路可修改直线／圆角折线／曲线；圆角折线采用走廊控制点，最多两次转弯，曲线提供两个控制点，设备接点保持连续圆周角度定位，并在八方向端口附近轻吸附。显式直线不自动改成折线。

“轻量吸附”默认开启，进入阈值为 **5 个 CSS 屏幕像素**，保持到 **8 个屏幕像素**后释放；使用当前 SVG 变换换算，适应画布和放大时保持近似一致手感。端点接近 0／45／90／135／180／225／270／315° 时吸附，其他位置仍为连续角度，不再全局按 5° 量化。选中设备或线路时仅显示相关圆盘的八个参考点。

设备、区域、整环、备注和标签的拖动可对齐其他设备边缘／中心、区域边缘／中线／四分位、画布关键线和环网中心／轴点／八分位。曲线控制点和真实接点另可贴合设备八向端口与区域交点；折线走廊只吸附其实际可调整轴。整区、整环的参考集合排除随动成员，避免吸附自身。环节点只使用同一椭圆上的轴点、参数八分位、等弧长八分位、原位置及邻居间等弧长中点；无效顺序或间距的候选会过滤，最终仍由模型约束检查。吸附不是自动避障或自动连接。

**图标对齐基准**只采用圆盘中心与半径，不采用包含下方名称、长文本、多行备注或移动过的名称的整体包围框。在同一 5px 触发范围内，图标中心对中心优先于同侧边缘及区域／画布辅助线；较弱参考即使已吸住，也必须让位于新进入范围的图标中心。相同优先级仍保留 8px 释放区间以减少抖动，中心不在触发范围时仍可使用边缘和区域定位。拖动名称只改变其偏移，不移动圆盘。

按住 **Alt** 临时暂停吸附，松开即可恢复；取消勾选可持续关闭。没有触发吸附的方向沿用所选网格步长，**Shift** 改为 1px，**Alt+Shift** 便于自由精调。方向键维持明确步长，不被吸附拉回。吸附状态、细辅助线与高亮点仅在手势期间出现，状态区保留固定宽高避免影响画布坐标；释放、取消或离开编辑后清除。参考点和辅助线不进入模型或静态 SVG／PNG。

环上设备只能沿共同椭圆移动，不能越过邻居；环段不提供自由折点。上方“移动环网”手柄移动整环及真实内部对象，右下手柄调整环的长短轴；两侧外部站点不随环移动，支线重新连接。锁定的设备或成员阻止相关移动。共享多环设备不做单独自由拖动，避免破坏其他环。

业务边仍以 `base_edge` 跟随基础边；选中业务色带会转选基础线，不产生新的物理连接。布局不修改成员 ID、主备身份、语义线型或拓扑事实。每个视图的坐标／路线／标签独立保存在 `views[view]` 的显式数组中；总览与详图可采用不同位置，事实映射保留。已编辑场景标记 `coordinates: manual`、`editor_version: 1`；该视图的 `edit_validation` 保存状态与待修条目。

撤销／重做按场景保存最多 80 步，跨视图撤销时回到对应视图；文件重新打开或导入时开始新的撤销历史。方向键移动选中对象，Shift 精调到 1px。“还原当前图”恢复打开或导入时的模型，可再撤销。拖动过程中提示区保持稳定，避免画布位置改变影响手势坐标。

“检查布局”检查设备／名称／备注与线路净空、组合标签、区域归属、画布边界、独立路径交叉和重叠；有问题的布局保留为明确的“编辑待修”草稿，导出的 SVG／PNG 也带此标记。此检查覆盖常见布局问题，不代替正式规范的全部验收门槛，也不自动消除交叉或重新优化布局。

“保存 HTML”将全部场景、已编辑视图、图标、字体、许可及编辑器内嵌为单一文件；重新打开默认浏览模式，可再次进入编辑。原页面的编辑选择框、手柄和临时提示不作为静态输出内容。“保存模型”保存当前完整 V2 场景及总览／详图；“导入模型”接受本格式的 JSON，验证坐标、端点、引用和样式后加载。同 ID 替换当前模型，新 ID 加入样板导航。导入不执行代码，不加载外部图标或资源；旧 Python 模型不混用。

编辑代码分为 `scripts/v2/editor-model.js` 的模型／几何操作、`scripts/v2/snap.js` 的纯近邻吸附与参照计算、`assets/v2/editor.js` 的手势、选择、历史和检查。构建时与原图元一同内嵌，不安装依赖。`verify_topology_v2_editor.js` 检查几何与模型不变量；`verify_topology_v2_editor_browser.py` 验证真实鼠标操作及保存／重开。

`verify_topology_v2_snapping.js` 验证屏幕阈值、保持区间、候选排除与环约束；`verify_topology_v2_snapping_browser.py` 验证真实八向拖动、两档缩放、Alt 按下／释放、开关、区域／环对齐、深浅界面、临时指南清理及 HTML／JSON／SVG 往返。
