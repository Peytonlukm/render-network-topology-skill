# Changelog

## 2.0.0 — 2026-10-30

- Add the V2 offline specimen workbook, semantic connection styles, ring geometry, light/dark themes, and bundled v1.0 design standard.
- Add browser layout editing, undo/redo, proximity snapping, validation, editable HTML and V2 JSON round trips, plus SVG/PNG export.
- Add 12 SST icon categories, deployment badges, and embedded IBM Plex Sans with its OFL license; other categories retain neutral fallbacks.
- Preserve the legacy Python renderer and models. V2 scenes use a separate model and curated coordinates; general automatic layout and graph-structure editing remain future work.
- Package the builder and verification tools so the skill can be cloned and used independently. Examples are synthetic; local project records and customer materials are excluded.
